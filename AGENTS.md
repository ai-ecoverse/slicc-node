# slicc-node

`@ai-ecoverse/slicc-node`: SLICC's local proxy (`slicc-node` bin) for pages on `*.sliccy.ai`. Node ≥ 24, ESM, plain JS. `src/protocol.js` is raw mode of `/api/fetch-proxy`, `src/security.js` the origin, host and key gate, `src/server.js` the server. The protocol is specified in README.md and must stay in step with slicc-kernel's `localProxyTransport` and slicc-swift. Lint with `slicc-lint`. No comments in any file. Agent guidance lives only in this AGENTS.md (≤1000 characters). Do not add CLAUDE.md. Unit tests stay in gitignored `test/unit/` (`npm run test:unit`); integration tests in `test/integration/` (`npm test`). Publish from `main` with semantic-release, fledgling trusted publishing, and shared-web's `node-release.yml` via local `release.yml`.
